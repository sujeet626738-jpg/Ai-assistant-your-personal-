# ESP32 AI Voice Assistant

An AI-powered voice assistant built using ESP32 and Python.

## Features
- Voice Interaction
- AI-powered Responses
- OLED Face Animation
- Speaker Output
- Wi-Fi Support
- ESP32 Based

## Hardware
- ESP32 DevKit V1
- OLED Display
- Microphone
- Speaker
- MAX98357 Amplifier

## Software
- Arduino IDE
- Python
- ESP-IDF
- GitHub
